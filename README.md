# Week 5: DOM Manipulation

## Overview
This project was completed as part of IYF Weekend Academy Season 12, Week 5. It covers JavaScript DOM manipulation, events, user interaction, and form handling.

## Main Project: Interactive To-Do List
The To-Do List application allows users to:
- Add tasks using the Add button or Enter key.
- Mark tasks as completed or active.
- Delete individual tasks.
- Filter tasks by All, Active, and Completed.
- View the number of remaining tasks.
- Clear all completed tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Practice Exercises
- DOM element selection and traversal
- Modifying text, HTML, attributes, and styles
- Creating, cloning, and removing elements
- Event listeners and the event object
- Keyboard shortcuts
- Event bubbling and event delegation
- Form handling
